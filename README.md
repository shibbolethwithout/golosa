# Голоса СССР

Каталог советских радиоспектаклей с поиском, тегами и фильтрами.

## Что это

Веб-каталог ~630 радиоспектаклей СССР. Аудио стримится с внешних
источников, локально хранятся только метаданные и обложки.

## Стек

- React 19 + Vite 8
- Tailwind CSS 4
- Zustand (состояние плеера, persist в localStorage)
- Fuse.js (fuzzy-поиск)
- Oxlint
